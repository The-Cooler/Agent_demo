项目说明

这是一个从零实现的最小可用 Agent 演示，用于展示 ReAct 循环、工具注册、多会话隔离、上下文管理与执行 trace。不依赖任何 Agent 框架。

真实功能

  • calculator：对数学表达式求值，支持 + - * / % ** 和括号
  • todo：当前会话的待办增删改查，数据写入本地 SQLite
  • read_docs：读取 data/docs/ 下已登记的文档

mock 数据

  • weather：返回预先写死的示例天气，不是实时数据，只覆盖北京、上海、深圳、杭州四个城市
  • search：检索 data/corpus.json 中的本地语料，不连接任何搜索引擎，语料共 5 条

界面数据

  • 会话列表中的示例会话、消息和待办均为本地使用产生的记录，保存在 data/agent.db

其他说明

  • 对话模型通过 OpenAI 兼容接口调用，具体模型由 .env 中的 OPENAI_MODEL 决定
  • 「执行过程」展示的是当前这一轮的工具调用步骤；刷新页面后，历史消息不保留步骤详情
